# CGS4144 Semester Project

## Scientific Question

Can we identify wild-type versus Trem2-knockout mouse samples based on gene expression?

## Link to Dataset

https://www.refine.bio/experiments/SRP119064

## Description of Data

RNA-seq data from mouse brain tissue comparing wild-type mice to mice with the Trem2 gene, a known Alzheimer's-risk gene, knocked out.
